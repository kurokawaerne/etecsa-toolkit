# toolkit-core (Rust)

Pure-Rust, dependency-free core that does the two jobs where a wrong answer costs the user money or safety: parsing ETECSA/Cubacel USSD & SMS responses in Spanish (saldo CUP, datos with vigencia, voz, SMS, bonos, roaming — plus transfer confirmations and plan purchases, returned as a typed `ParsedResponse`) and antifraud sender matching (the official ETECSA / Cubacel / PAGOxMOVIL / ENZONA / Nauta sender catalogue decoded from the signed `official-senders-v2.json`, plus impersonation heuristics for brand-claiming messages from unofficial senders). The app calls it from Kotlin through JNI (`--features jni`): `RustCore.nativeParseResponse(text)` returns the result as a hand-rolled JSON string, and `nativeIsOfficialSender` / `nativeLooksLikeImpersonation` return booleans — every binding is a thin, panic-free wrapper over the pure functions, which are covered by `cargo test` (25 tests with realistic operator strings).
